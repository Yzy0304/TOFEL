# 托福卡片网站设计
用户已要求开始实现。每日 20–30 分钟只用于卡片，不安排完整邮件或 Discussion。
## 范围
182 张中文解释与英文例句卡，Email 62、Discussion 60、Listen and Repeat 36、Interview 24。保留原编号与来源说明。
首页展示今日预算、到期复习、新卡与四个模块；素材库支持模块、领域、关键词筛选。
学习页支持中译英主动回忆、填空、拼句、语音播放；复述模式先隐藏英文再播放。可选本地录音回听，不作官方评分。
每张卡展示语境、搭配注意与自编例句；作答后自行标记不记得、有点印象、记得，安排间隔复习。
进度页区分接触过、待加强、稳定回忆、能换场景使用。日历显示实际分钟。20 与 30 分钟可切换，暂停、离开与闲置不计时。
旧卡优先，新卡通常 4 张，上限 6，周日不自动加新卡。漏学顺延，不堆积日历债务。
localStorage 保存，JSON 导入导出。导入须验证版本、数据类型、卡片编号与范围；失败不能破坏已有进度。
静态 HTML/CSS/JS 和本地 JSON，无服务器无 API 密钥。部署 GitHub Pages；原 Word 和截图不上传。
## 视觉
奶油色背景，绿色主按钮，橙色强调，清晰中文导航。桌面侧栏与手机底部导航，卡片聚焦学习，避免装饰干扰。
## 验证
Node 单元测试覆盖队列、间隔、日期、掌握统计、导入校验与填空匹配；浏览器验证学习流程、存储恢复、筛选和手机布局。
