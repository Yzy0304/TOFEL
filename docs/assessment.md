# 答案评判与掌握度

## Mac 本机使用

需要 Node.js 22 或更新版本；服务没有额外运行依赖。双击仓库中的 `启动词境.command`，或在项目目录运行 `npm start`。终端会显示本机地址，默认为 [http://127.0.0.1:4173](http://127.0.0.1:4173)。保持终端运行。

在本机网站的「学习设置 → 答案评判与 ChatGPT 订阅」点击 Continue with ChatGPT，随后在官方授权页确认应用名称 **TOEFL Card Studio** 和允许的订阅用量。授权后回到学习设置，点击「刷新连接状态」，从账户实际可用模型中选择评判模型。

本服务使用官方 Sign in with ChatGPT 的本地应用授权路线。能否授权、可用模型和额度由你的账户及 OpenAI 当前规则决定；不保证所有订阅账户均可用。不会读取或复用 Codex 登录令牌，不会自动转用按量计费的 API Key。

凭据保存在 Mac 的 `~/.config/toefl-card-studio/accounts.json`，文件权限为 0600、目录为 0700，位于仓库外；不进入学习备份、浏览器存储或 GitHub。支持选择已保存账户、新增账户、断开当前账户。断开时尝试撤销远程会话；若未确认撤销，页面会提示去 ChatGPT 设置断开应用。

## 如何作答

先根据中文独立输入核心短语或一个符合含义的句子，点击「提交评判」。普通回忆接受合理同义表达；填空会结合复原后的句子判断语法。Interview 卡片中的问题和完整示例帮助迁移，日常回忆仍以卡片核心含义为准，不强迫背整篇范例。

- **语法错误**：指出错误片段、原因和最小修改，缩短复习间隔。
- **表达不地道**：语法基本成立，但搭配、用词或语域在当前语境中明显不自然；安排次日复习。
- **完全正确**：自然、语法正确且符合题意，延长复习间隔。

题意匹配另行检查。即使语言正确，答非所问也不记为掌握；界面优先显示「题意不符」。听后复述和词块拼句要求复现参考原句，不用同义改写代替原句。

与已校验参考表达一致时，可直接在浏览器完成匹配校验，明确标记为「参考表达匹配校验」。其他表达在本机发送给所选 ChatGPT 模型。等待模型时暂停学习计时；连接失败、额度不足、模型不确定、返回格式不一致或未收到完整结束事件时，不写入成绩。模型可能判断失误，可查看原句与纠正理由后自行核对。

## 掌握度证据

仅当天首次、未看参考答案和反馈的独立作答更新掌握度。看过答案后的重试、当天在素材库看到过的表达、当天重复作答，以及先自行标记过的卡片，只记录为纠错练习，不增加独立正确次数。错误后的当天改对不会抵消首次错误。

两次不同日期的连续独立正确，才计为「经作答验证稳定」。后续独立出现语法、自然度或题意问题，会重新进入待加强。保留原来的自评回忆指标，与独立作答证据分别展示。

每张卡保留累计独立作答统计与正确日期，最近 200 次原句和详细反馈保存在当前浏览器，支持学习备份导出导入；历史详情裁剪不会清空每卡累计统计。评判只针对文字，不诊断发音、不换算托福分数。

## 手机与在线版

GitHub Pages 和手机上的在线版继续提供卡片、复述、参考匹配、自行标记与备份功能；本次没有增加公网模型服务。非参考表达的 AI 评判在 Mac 本机版启用。本机服务只监听 127.0.0.1，不向局域网或互联网公开账户凭据或推理接口。

各浏览器进度仍独立保存。Mac 和手机之间使用原有 JSON 备份导入导出；导入会替换该浏览器的现有进度，请先导出保留备份。已有在线版记录也可导出后导入本机版。

2026-10-20：275 项自动化测试通过，覆盖旧存档、三类反馈协议、跨日独立掌握证据、提示记录、账户切换与退出竞态、签名及权限校验、断流与接口保护。浏览器已检查参考匹配、模拟语法与自然度反馈、纠错重试、进度记录，以及新开队列仍保留当天提示证据。
