# 多设备学习进度与备份

## 开始同步
在「学习设置 → 多设备学习进度」填写 Supabase 项目团队的邮箱，发送登录邮件。用同一台设备、同一个浏览器打开邮件中的 Sign in 链接。手机与 Mac 使用同一邮箱，登录后自动合并本机与云端进度。

这是托福应用自己的同步账号，与 Supabase 管理台登录及 ChatGPT 订阅连接分别使用。默认内置邮件服务仅向项目团队邮箱发信，频率有限；供自己在多台设备使用，不需要升级套餐。对外开放注册需另配邮件服务。

在线版地址：https://yzy0304.github.io/TOFEL/ 。Mac 本机版地址：http://127.0.0.1:4173/ 。两端登录同一同步账号后共享进度；ChatGPT 评判仍限本机。

## 保存与同步
学习操作先保存到浏览器，联网且已登录时自动同步；页面显示同步状态。页面打开后约每 30 秒检查更新，完成学习操作后约 3 秒尝试上传；联网恢复和重新打开页面时也会检查。

断网时，在已加载的页面中仍能学习和保存，联网后补传；尚未提供完整网站离线缓存，断网后不能保证重新打开网站。关闭页面过快时，尚未上传的记录会在下次打开后同步。未登录时只能本机保存。

服务按登录账号隔离数据，使用版本比较处理并发，两端同时学习不会整份覆盖。新增事件按唯一编号去重；同一张卡同日多次独立作答只计一次掌握证据。时长按设备和日期累计，重复同步不累加；若同时在两台设备保持学习，两端实际计时会相加。

## 原有记录
旧版保存的是汇总快照，不能恢复所有逐次学习事件。迁移保留原始存档；合并时保留不同卡片、日期和原始快照，重叠日的旧次数和时长采用最大值，不直接相加。旧记录与新增事件发生时间重叠时，同样按保守下界统计，因此合并后的次数和时长不一定等于两端之和。原始证据保留在备份中。

原来的手机、电脑记录仍需分别在各自原浏览器中登录一次，才能上传合并。新版无法自动读取另一浏览器里从未上传过的旧记录。

## 导入与恢复
导出包含事件日志的 JSON 备份，版本号为 2。导入兼容旧版备份，并展示卡片数与日期数的合并预览。确认后自动保存、下载合并前备份，不替换整份进度。

「下载合并前备份」可取回最近一次合并前的记录；「下载迁移前原始存档」保留本浏览器第一次启用同步前的旧记录。录音不包含在备份内。

退出同步账号会保留本机学习记录与账号归属；为防止串号，其他账号不会自动接收这些数据。若要使用其他账号，请使用另一个浏览器配置文件。

## 数据范围
云端同步卡片进度、学习日期和时长、答案曝光、文字作答及评判反馈、学习设置。录音、麦克风内容、ChatGPT 凭据、数据库密码和管理密钥不上传。浏览器只包含公开项目 URL 与 publishable key；云端行级规则限制账号只能读写自己的记录。

## 容量
当前每份日志上限 4 MiB、5 万条事件，达到限制会停止新增写入并提示导出，不会静默删除历史。长期大量使用前需增加日志归档机制。
