# 学习记录云同步

用户已确认 Supabase 并要求直接完成配置和网站功能。

## 范围
使用现有 Supabase 项目，邮箱一次性链接登录，本地优先保存，按账号隔离云端记录；手机和 Mac 登录同一账号同步。保留独立作答、提示曝光、跨日掌握判定。

## 数据
不可变学习事件用 UUID 去重；时长用设备/日期累计计数合并。历史存档保留原件并保守合并，重叠汇总取最大值，不能据缺失的旧事件制造精确总次数。旧记录和新增事件按日期分界，迁移当天只采用保守汇总。新备份包含同步日志。

## 同步
云端每个账号一份文档，版本比较后原子更新；冲突重新读取合并，上传中产生的新事件保留。离线保留待同步数据，恢复联网自动重试。登录账号绑定本地数据；其他账号不自动接收原账号数据。会话、录音、模型凭据不上传。

## 验证
覆盖重复导入、并发冲突、离线恢复、错误保留、账号切换、跨设备首次独立判定、RLS隔离、静态和本机版本资源。

## 2026-10-21 配置验证
免费内置邮件模板不可自定义验证码，改为默认 Magic Link。在线与 127.0.0.1:4173、localhost:4173 回调已保存。匿名 SELECT 和保存 RPC 均返回 HTTP 401。真实本人账号登录由用户打开邮件链接完成。
