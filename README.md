# 词境 TOEFL Card Studio

每天 20–30 分钟的托福表达卡片网站。重点是 Email 与 Academic Discussion，穿插场景复述和 Interview。完整写作不属于每日卡片任务。

## 使用
- 今日学习：旧卡优先，每天默认最多新学 16 张，周日只复习。
- 素材库：按模块、领域、关键词查找；单纯查看不计为掌握。
- 主动回忆、语境填空、词块拼句、听后复述四种练法。
- 回忆后自评“不记得／有点印象／记得”；不同日期两次正确才计为稳定回忆。
- 默认 30 分钟，可早晚各 15 分钟；20/30 分钟可切换，支持暂停、继续、后台与闲置暂停。
- 设置支持 0–16 张新卡。旧存档的默认 4 张或 12 张计划会升级为 16 张 / 30 分钟，学习记录保留；手动设置过的其他额度保留，新版再次手动调低后也会保留。升级后重建当天队列，今日已学数量仍从额度中扣除。
- 学习记录自动保存在本机；可通过邮箱登录同步 Mac 与手机。设置页导出 JSON 备份，导入前预览并合并，不直接覆盖。详见 [同步说明](./docs/sync.md)。
- 语音来自浏览器英文语音；录音需要 HTTPS 或 localhost，文件仅保存在页面内存中，不上传、不自动评分。

## 内容
Email 62 张，Discussion 60 张，场景复述 36 张，Interview 60 张，共 218 张。例句为主题整理与自编，来源说明见卡片及设置页，不是官方预测题。原培训机构 Word 与截图不在仓库内。

Interview 覆盖 12 个主题，每主题 5 张，均含访谈问题、核心表达、例句、45–95 词的原创展开回答和中文搭配提示。详情及卡片答案中可查看和播放展开示例。示例以 ETS 评分要求为写作方向，未经官方评分。16 张新卡指核心表达卡，不要求背完 16 篇回答。素材充足时首轮配比为 Email 5、Discussion 5、场景复述 2、Interview 4。

## 答案评判

输入后可提交「语法错误／表达不地道／完全正确」三类评判，显示问题位置、原因、最小修改和可选自然表达，并另行检查题意。只有当天首次未看答案的独立作答更新掌握度；不同日期连续两次独立正确才计为经作答验证稳定。错误后的纠错重试单独记录，不刷掌握度。

Mac 本机版可通过官方 Sign in with ChatGPT 授权使用订阅额度。在线版和手机保留基础卡片及参考匹配功能。[使用说明、隐私与研究参考](./docs/assessment.md)。

## 本地运行
需要 Node.js 22+，无需安装额外运行依赖。双击 `启动词境.command` 或运行 `npm start`，打开终端显示的 http://127.0.0.1:4173 ，在学习设置中连接 ChatGPT 订阅。
仅需静态卡片功能时可运行 `npm run start:static`；静态服务不提供模型接口。不要直接双击 index.html，因为浏览器会限制本地 JSON 读取。

验证：`node --test tests/*.test.mjs`；语法检查：`node --check app.js`。

## GitHub Pages
将项目推送到 GitHub 后，进入仓库 Settings → Pages，选择 Deploy from a branch，选择网站分支和 /(root)，保存。所有资源使用相对路径，支持项目子路径。也可以启用随附的 Pages Actions 工作流。

## 文件
- index.html / styles.css：响应式界面
- app.js：学习交互、语音、录音和本地保存
- core.js：队列、间隔复习、独立作答证据、进度与导入校验
- assessment.js / assessment-ui.js：评判协议与反馈界面
- server.mjs / local：本机授权与模型评判服务（不部署到 Pages）
- data/cards.json：素材库
- docs/handbook.md：完整备考手册
- docs/study-plan.md：每日打卡表
- tests：学习规则与内容验证

实际学习时长与自评记录不能替代官方托福评分。
